# 1660S 本机开跑（照着做）

适用：R5 9600X · GTX **1660 Super 6GB** · 64G 内存。  
目标：本地 ComfyUI + 本仓库网页，用无审查向 SD1.5 出图（衣服/身体细节由提示词决定，**无在线过滤**）。

硬红线不变：禁止未成年人相关内容。

## 版本钉死（重要）

本机当前可用组合（2026-09-08 已验证）：

- ComfyUI：**v0.3.26**（`vendor/ComfyUI` 已 checkout 到该 tag）
- Python：**3.11.9** + venv
- PyTorch：**2.6.0+cu124**
- 主模型：`DreamShaper_8_pruned.safetensors`

勿随便 `git pull` 到 ComfyUI 最新 master：新版 `comfy_kitchen` 与 Torch 2.6 不兼容会起不来。  
要升级时另开实验目录，不要动这套能跑的 venv。

## 一句话结论

- **能去掉衣服限制吗？** 能。用本地 NSFW 友好检查点（本机已下 **DreamShaper 8**）+ 明确提示词即可；ComfyUI **没有** Midjourney 那种衣着审查。
- **不用时会拖慢系统吗？** 模型躺硬盘不影响。**关掉 ComfyUI 窗口**就不会占显存。

## 每次开跑（两窗口）

### 窗口 1：ComfyUI

仓库根目录：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-comfyui-1660s.ps1
```

等到出现：`To see the GUI go to: http://127.0.0.1:8188`  
保持窗口开着。

### 窗口 2：前端

```powershell
npm run dev
```

浏览器打开：http://127.0.0.1:5173  
（若开了 Clash/代理，不要用 `localhost`，容易白屏；直连 `127.0.0.1`。）

也可：`powershell -ExecutionPolicy Bypass -File .\scripts\start-frontend.ps1`

### 页面里

1. 确认满 18 岁。
2. 顶部选 **「机器 B · 1660 Super」**（分辨率会变成约 640×960）。
3. checkpoint 选 `DreamShaper_8_pruned.safetensors`。
4. **删掉** 默认里的 `score_9, score_8_up...`（那是 Pony 用语）。
5. 用自然语言或短标签写正向词 → 开始生成。

## 提示词怎么写（去掉衣服 / NSFW）

本地没有「禁止裸体」开关。能否出，取决于 **模型是否见过这类数据** + **你写没写清楚**。

正向示例（成人、明确同意语境，自行改）：

```text
beautiful adult woman, nude, detailed skin, natural lighting, looking at viewer
```

或半裸：

```text
beautiful adult woman, topless, jeans, detailed face, soft light
```

负向建议：

```text
blurry, extra fingers, bad anatomy, deformed, child, loli, shota, underage, teen
```

说明：

- DreamShaper 8 对 NSFW 友好（作者说明 V7/V8 加强过 NSFW），写实/半二次元都行。
- 若仍「穿太多」：加强 `nude` / `completely nude`，并在负向加 `clothes, dressed, bra, panties`。
- 若崩手崩脸：降到 **512×768**，步数 20–28，CFG 5–7。

更细的类型对照见 `docs/06-prompts.md`。

## 补下模型（可选第二套）

主模型直链（Hugging Face，无需 Civitai 登录）：

```powershell
curl.exe -L -o vendor\ComfyUI\models\checkpoints\DreamShaper_8_pruned.safetensors `
  "https://huggingface.co/Lykon/DreamShaper/resolve/main/DreamShaper_8_pruned.safetensors"
```

写实向备选（约 2GB）：

```powershell
curl.exe -L -o vendor\ComfyUI\models\checkpoints\Realistic_Vision_V5.1_fp16-no-ema.safetensors `
  "https://huggingface.co/SG161222/Realistic_Vision_V5.1_noVAE/resolve/main/Realistic_Vision_V5.1_fp16-no-ema.safetensors"
```

更偏「去衣 / 色情」的专项 merge（如 URPM、EpicRealism 等）多在 [Civitai](https://civitai.com)，需账号 API token，搜：`nsfw sd1.5`、`undress`、`nude`。下好仍放进 `models/checkpoints`。

**1660S 不要下：** 全精度 Flux、CHROMA、视频大模型、优先 Pony XL。

## 关停

两个终端 `Ctrl+C`。模型文件可留着，不占运行速度。

## 常见故障

| 现象 | 处理 |
|------|------|
| 前端连不上 | 先开 Comfy；确认 8188 |
| CUDA OOM | 选 1660S 档；512×768；去掉 LoRA |
| 一直穿衣服 | 提示词不够直白；换 DreamShaper / Civitai NSFW 检查点 |
| 超时 | 1660S 慢，可等或改小分辨率 |
| `python` 不对 | start 脚本会优先用 `venv\Scripts\python.exe` |
